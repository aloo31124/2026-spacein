## git commit2
[fix] # 修正[安卓]使用[aab]部屬到 Play Console 出現簽署金鑰錯誤。
[why] 兩個原因：
- 選錯選單：Build > Generate App Bundles or APK > Generate Bundles 
  會根據目前 Build Variant 產生，若選的是 debug 就只產生 debug AAB。
- 簽署設定：即使產生 release，Android Studio 不一定會讀 keystore.properties，需透過正確流程指定。

[how] 修正方式:

正確方式：使用 Generate Signed Bundle

Android Studio 中：
- 選單點 Build → Generate Signed Bundle / APK...
- 選 Android App Bundle → Next
- 填入 keystore 資訊：
- Key store path: C:\Users\ASUS\Desktop\2026-spacein\frontend\android\app\release\key20241001.jks
- Key store password: 123456
- Key alias: key20241001.jks
- Key password: 123456
- Next → 選 release → Finish
- AAB 會產生在：
- frontend/android/app/release/app-release.aab

或者：直接用 Gradle 指令（最可靠）
不需要 IDE，直接在終端機執行：
- cd frontend/android && ./gradlew bundleRelease --no-daemon
- 輸出在 app/build/outputs/bundle/release/app-release.aab，這是最穩定的方式，建議用這個。
