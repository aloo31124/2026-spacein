這裡的需求是根據請求的 `user` 條件，在 Firestore 的 `Users` 集合中查找符合的使用者資料，並支持 **模糊搜尋**（特別是 `name` 字段，需支持中文字模糊匹配）。  

---

## **方案設計**
### **1. Firestore 查詢條件**
- 若請求中有 `name`，則使用 **Firestore `where` + `array-contains-any` 或 `startAt/endAt`** 來支持**模糊搜尋**。
- 其他字段則 **完全匹配**。

### **2. 主要邏輯**
- **`name` 欄位** → 使用 `startAt(name).endAt(name + "\uf8ff")` 來模糊查詢。
- **其他欄位** → 若有指定，則加入 Firestore 的 `where()` 條件。
- 若查詢條件為空，則回傳 **400 錯誤**。

---

## **1️⃣ 更新 `user.model.js`**
```javascript
const db = require('../firestore');

class UserModel {
    constructor({ name, mail, state, phone, role, pay, password, createdAt }) {
        this.name = name || "";
        this.mail = mail || "";
        this.state = state || "未設定";
        this.phone = phone || "";
        this.role = role || "未知";
        this.pay = pay || "無";
        this.password = password || "";
        this.createdAt = createdAt || new Date();
    }

    // 🔍 查詢符合條件的使用者
    static async select(user) {
        let query = db.collection('Users');
        let hasFilter = false;

        // 🔹 1. 處理 `name` 欄位的模糊查詢 (支援中文字)
        if (user.name) {
            query = query.orderBy('name').startAt(user.name).endAt(user.name + "\uf8ff");
            hasFilter = true;
        }

        // 🔹 2. 其他完全匹配欄位
        const filters = ['mail', 'state', 'phone', 'role', 'pay', 'password', 'createdAt'];
        filters.forEach((field) => {
            if (user[field]) {
                query = query.where(field, '==', user[field]);
                hasFilter = true;
            }
        });

        if (!hasFilter) {
            throw new Error("請至少提供一個搜尋條件");
        }

        const snapshot = await query.get();
        if (snapshot.empty) return [];

        return snapshot.docs.map(doc => ({ id: doc.id, ...doc.data() }));
    }
}

module.exports = UserModel;
```

## **2️⃣ 更新 `user.service.js`**
```javascript
const UserModel = require('../models/user.model');

/* 🔍 搜尋使用者 */
exports.searchUserList = async (user) => {
    try {
        if (!user || Object.keys(user).length === 0) {
            throw new Error("請至少提供一個搜尋條件");
        }

        console.log(`[${new Date().toISOString()}] 搜尋使用者條件:`, user);

        const userList = await UserModel.select(user);
        console.log(`[搜尋結果]`, JSON.stringify(userList, null, 2));

        return userList;
    } catch (error) {
        console.error(`[searchUserList] 發生錯誤:`, error.message);
        throw new Error(`搜尋失敗: ${error.message}`);
    }
};
```

## **3️⃣ 更新 `managerRoom.api.controller.js`**
```javascript
const userService = require('../../services/user.service');

exports.searchBookingUser = async (req, res) => {
    try {
        const { user } = req.body;
        if (!user || typeof user !== "object") {
            return res.status(400).json({ result: '400', error: "請提供有效的 user 查詢條件" });
        }

        const userList = await userService.searchUserList(user);
        res.status(200).json({ result: '200', data: userList });
    } catch (error) {
        res.status(500).json({ result: '500', error: error.message });
    }
};
```

## **📌 方案優勢**
1. **支援中文字的模糊搜尋**
   - `startAt(name).endAt(name + "\uf8ff")` 可搜尋包含 `name` 的使用者。

2. **彈性條件搜尋**
   - `mail`, `phone`, `state` 等欄位可單獨匹配，滿足不同情境的查詢需求。

3. **錯誤處理**
   - 若沒有提供任何條件，則回傳 `400` 錯誤。
   - 若 Firestore 查詢錯誤，則 `500` 回應錯誤訊息。

---

這樣的設計能滿足搜尋需求，並且在 Firestore 中效率較高 🚀
