在 `joinRoomByRoomId` 方法中，`roomToSiteList` 和 `roomList` 需要进行 **基于 `roomId` 的 Join**，
也就是将 `roomToSiteList` 的 `roomId` 与 `roomList` 的 `id` 进行匹配，从而获取完整的教室信息。  

---

### **修正 `joinRoomByRoomId` 方法**
**实现思路：**  
1. **获取 `roomList`**：包含所有教室的数据。  
2. **转换 `roomList` 为 `Map`**：以 `roomId` 为 `key`，方便快速查找对应教室。  
3. **遍历 `roomToSiteList`**，查找 `roomId` 对应的 `room`，然后合并数据。  

    ```js
    static async joinRoomByRoomId(roomToSiteList) {
        const roomList = await Room.getAllRoomList();

        // 建立 roomId 映射表 (Map)
        const roomMap = new Map(roomList.map(room => [room.id, room]));

        // Join 数据
        const joinedList = roomToSiteList.map(site => {
            const room = roomMap.get(site.roomId) || {}; // 若找不到，则返回空对象
            return {
                ...site,
                roomName: room.name || "未知教室",
                roomOwner: room.ownerId || "未知擁有者",
            };
        });

        console.log("Joined Room & Site List: ", joinedList);
        return joinedList;
    }
```

---

### **完整流程**
1. `selectSiteJoinRoomList(roomToSite, pagingParam)`  
   - 先从 `select(roomToSite, pagingParam)` 获取分页后的 `roomToSiteList`。  
   - 然后调用 `joinRoomByRoomId(roomToSiteList)`，将 `roomToSiteList` 与 `roomList` 进行 `join` 处理。  

2. `joinRoomByRoomId(roomToSiteList)`  
   - **用 `Map` 加速查询**，避免 `O(N^2)` 的嵌套遍历，提高性能。  
   - `roomId` 匹配不到时，提供默认值，避免 `undefined` 错误。  
   - `joinedList` 结合座位和教室数据，返回完整结果。

### **优化点**
