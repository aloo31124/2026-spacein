這裡我們將使用 **Angular Router** 來實現**左側選單點擊時高亮顯示，並切換對應的 Component**。  

---

## **📌 1️⃣ 更新 `app-routing.module.ts`**
我們需要設定 `path` 對應的元件，讓 Router 負責顯示內容。  

```typescript
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { RoomDashboardComponent } from './manager-room/components/room-dashboard/room-dashboard.component';
import { SearchBookingUserComponent } from './manager-room/components/content/search-booking-user/search-booking-user.component';
import { SearchRoomComponent } from './manager-room/components/content/search-room/search-room.component';
import { SearchSiteComponent } from './manager-room/components/content/search-site/search-site.component';
import { SearchBookingComponent } from './manager-room/components/content/search-booking/search-booking.component';

const routes: Routes = [
  { path: '', redirectTo: '/dashboard/booking-user', pathMatch: 'full' }, // 預設進入預約者管理
  { path: 'dashboard', component: RoomDashboardComponent, children: [
      { path: 'booking-user', component: SearchBookingUserComponent },
      { path: 'room', component: SearchRoomComponent },
      { path: 'site', component: SearchSiteComponent },
      { path: 'booking', component: SearchBookingComponent }
    ]}
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],
  exports: [RouterModule]
})
export class AppRoutingModule {}
```
✅ **設定 `dashboard` 內的 `children` 路由，對應到不同的管理功能**  
✅ **當進入 `dashboard` 時，預設顯示 `booking-user`（預約者管理）**  

---

## **📌 2️⃣ 更新 `room-dashboard.component.html`**
讓選單按鈕根據 **當前路由** 顯示反白樣式，並用 `<router-outlet>` 顯示對應內容。  

```html
<div class="manager-container">
    <div class="manager-menu">
        <button routerLink="/dashboard/booking-user" routerLinkActive="active">預約者管理</button>
        <button routerLink="/dashboard/room" routerLinkActive="active">教室管理</button>
        <button routerLink="/dashboard/site" routerLinkActive="active">座位管理</button>
        <button routerLink="/dashboard/booking" routerLinkActive="active">預約紀錄管理</button>
    </div>
    <div class="manager-content">
        <router-outlet></router-outlet> <!-- 顯示對應的 Component -->
    </div>
</div>
```
✅ **使用 `routerLink` 設定按鈕對應的路由**  
✅ **使用 `routerLinkActive="active"` 讓選擇的按鈕高亮顯示**  
✅ **使用 `<router-outlet>` 動態載入對應的 Component**  

---

當然可以不使用 `app-routing.module.ts`，改用 **`Router` 物件動態切換組件**，這樣可以**完全控制選單的行為**，適合小型專案或不希望拆分路由設定的情境。  

---

## **📌 1️⃣ 更新 `room-dashboard.component.html`**
將 `button` 點擊後，透過 `(click)` 呼叫 `setActiveComponent()`，動態切換顯示的 Component。  

```html
<div class="manager-container">
    <div class="manager-menu">
        <button [class.active]="activeComponent === 'booking-user'" (click)="setActiveComponent('booking-user')">
            預約者管理
        </button>
        <button [class.active]="activeComponent === 'room'" (click)="setActiveComponent('room')">
            教室管理
        </button>
        <button [class.active]="activeComponent === 'site'" (click)="setActiveComponent('site')">
            座位管理
        </button>
        <button [class.active]="activeComponent === 'booking'" (click)="setActiveComponent('booking')">
            預約紀錄管理
        </button>
    </div>
    <div class="manager-content">
        <ng-container *ngIf="activeComponent === 'booking-user'">
            <app-search-booking-user></app-search-booking-user>
        </ng-container>
        <ng-container *ngIf="activeComponent === 'room'">
            <app-search-room></app-search-room>
        </ng-container>
        <ng-container *ngIf="activeComponent === 'site'">
            <app-search-site></app-search-site>
        </ng-container>
        <ng-container *ngIf="activeComponent === 'booking'">
            <app-search-booking></app-search-booking>
        </ng-container>
    </div>
</div>
```
✅ **不使用 Router，而是透過變數 `activeComponent` 來切換顯示的 Component**  
✅ **點擊時切換 `activeComponent`，並動態顯示對應組件**  
✅ **透過 `[class.active]` 設定按鈕選中狀態**  

---

## **📌 2️⃣ 更新 `room-dashboard.component.ts`**
```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-room-dashboard',
  templateUrl: './room-dashboard.component.html',
  styleUrls: ['./room-dashboard.component.scss']
})
export class RoomDashboardComponent {
  activeComponent: string = 'booking-user'; // 預設顯示「預約者管理」

  setActiveComponent(component: string) {
    this.activeComponent = component;
  }
}
```
✅ **初始 `activeComponent` 為 `booking-user`（預設顯示「預約者管理」）**  
✅ **點擊按鈕時，動態變更 `activeComponent`，觸發畫面更新**  

---
