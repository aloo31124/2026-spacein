列出所有 ng cli 所有指令:
------------------------------------------------

以下是 **Angular CLI（`ng` 指令）** 的完整指令列表，並附上簡要說明：  

---

## 📌 **1. 開發相關指令**
| 指令 | 說明 |
|------|------|
| `ng new <專案名稱>` | 建立新的 Angular 專案 |
| `ng serve` 或 `ng s` | 啟動開發伺服器，預設為 `http://localhost:4200/` |
| `ng build` | 建立專案的可部署版本（預設輸出至 `dist/`） |
| `ng build --prod` | 建立 **生產環境** 版本，會進行最佳化 |
| `ng test` | 以 Jasmine/Karma 進行單元測試 |
| `ng e2e` | 執行端對端（E2E）測試 |
| `ng lint` | 使用 ESLint 檢查程式碼品質 |
| `ng update` | 更新 Angular CLI、依賴套件（如 RxJS、TypeScript） |

---

## 🏗 **2. 產生（Generate）相關指令**
| 指令 | 說明 |
|------|------|
| `ng generate component <名稱>` 或 `ng g c <名稱>` | 建立新的元件 |
| `ng generate service <名稱>` 或 `ng g s <名稱>` | 建立新的服務 |
| `ng generate module <名稱>` 或 `ng g m <名稱>` | 建立新的模組 |
| `ng generate directive <名稱>` 或 `ng g d <名稱>` | 建立新的指令 |
| `ng generate pipe <名稱>` 或 `ng g p <名稱>` | 建立新的管道（Pipe） |
| `ng generate guard <名稱>` 或 `ng g g <名稱>` | 建立路由守衛（Route Guard） |
| `ng generate interceptor <名稱>` | 建立 HTTP 攔截器 |
| `ng generate resolver <名稱>` | 建立路由 Resolver |
| `ng generate enum <名稱>` | 建立 Enum |

---

## 🌍 **3. 伺服器與設定**
| 指令 | 說明 |
|------|------|
| `ng config <key> <value>` | 設定 Angular CLI 的設定值 |
| `ng analytics on/off` | 開啟或關閉 Angular CLI 分析 |
| `ng version` | 顯示 Angular CLI 版本資訊 |

---

## 🔥 **4. 其他實用指令**
| 指令 | 說明 |
|------|------|
| `ng add <package>` | 安裝並設定 Angular 相關套件（如 `ng add @angular/material`） |
| `ng xi18n` | 產生國際化（i18n）語言檔 |
| `ng deploy` | 部署 Angular 應用程式 |
| `ng extract-i18n` | 提取翻譯字串（國際化 i18n） |
| `ng run <project>:command` | 手動執行指定的 Angular 指令 |
| `ng doc <關鍵字>` | 在官方文件中搜尋特定關鍵字 |

---

## 🏁 **常用範例**
1️⃣ **建立新專案**：
```sh
ng new my-angular-app
cd my-angular-app
ng serve
```
---

2️⃣ **建立元件與服務**：
```sh
ng g c components/my-button
ng g s services/auth
```
---

3️⃣ **建置生產環境並部署**：
```sh
ng build --configuration=production
ng deploy
```
---

這些是 Angular CLI 最常用的指令，如果你需要更詳細的說明，可以使用：
```sh
ng help
```
這會列出完整的 CLI 說明！🎉
