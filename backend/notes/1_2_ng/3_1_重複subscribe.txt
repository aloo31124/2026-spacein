造成冗於, 請遵守順序: 
檢查擁有者信箱 -> 擁有者 綁定 -> 角色綁定
進行精簡


    // 檢查擁有者信箱是否存在

      .getOwner(this.ownerEmail)

        const owner = res.result;
        if(!owner) {
          alert("查無資料");
          return
        }
        if(owner.error) {
          alert(res.result.error);
          return;
        }

為了避免巢狀地獄，我們可以使用 RxJS 的 `switchMap` 串接三個非同步流程，並用 `tap` 插入邏輯判斷或顯示訊息。這樣寫起來 **邏輯清楚**、**錯誤集中處理**、**程式碼乾淨好維護**。

---

### ✅ 精簡後寫法（依順序串接三個 API）

```ts
import { switchMap, catchError, tap } from 'rxjs/operators';
import { of, EMPTY } from 'rxjs';

this.accountService.getOwner(this.ownerEmail).pipe(
  tap(res => {
    const owner = res.result;
    console.log("booker select owner 2:", owner);

    if (!owner) {
      alert("查無資料");
      throw new Error("查無資料");
    }

    if (owner.error) {
      alert(owner.error);
      throw new Error(owner.error);
    }

    // 儲存 owner 以供下一步使用
    this.selectedOwner = owner;
  }),
  switchMap(() => {
    return this.accountService.postUserToOwner(userId, this.selectedOwner.id).pipe(
      tap(res => {
        if (!res.result) {
          alert("擁有者 綁定失敗");
          throw new Error("擁有者 綁定失敗");
        }
        alert("擁有者 綁定成功");
      })
    );
  }),
  switchMap(() => {
    return this.accountService.postUserToRole(userId).pipe(
      tap(res => {
        if (!res.result) {
          alert("角色 綁定失敗");
          throw new Error("角色 綁定失敗");
        }
        alert("角色 綁定成功");
      })
    );
  }),
  catchError(err => {
    console.error("流程中斷:", err.message);
    return EMPTY; // 停止流程
  })
).subscribe(() => {
  // 全部成功，導頁
  this.router.navigate(["/home"]);
});
```

---

### ✅ 整理重點

| RxJS 操作符 | 用法說明 |
|-------------|----------|
| `tap`       | 插入邏輯判斷或顯示提示（但不改變資料） |
| `switchMap` | 串接非同步流程，並保持流程順序 |
| `catchError`| 集中處理錯誤，避免巢狀 |
| `throw new Error()` | 主動中斷流程，讓 catchError 接住 |
| `EMPTY`     | 回傳空 observable，停止後續動作 |

---

### ✅ 額外小提醒

- 若你不想用 `this.selectedOwner` 暫存資料，也可以用 `map` 搭配 `switchMap` 傳遞 owner。
- 若三者中任一發生錯誤，會中斷整個流程，這樣 UX 上較為清楚一致。

有需要我幫你加 loading 狀態或加上 debounce 功能，也可以一起補上！
