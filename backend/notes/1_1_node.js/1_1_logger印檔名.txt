### **如何取得當前執行的檔案名稱與行號？**  

在 `logger.js` 中，可透過 **`Error().stack` 堆疊資訊**，解析出當前執行的檔案名稱與行號。  

---

### **實作步驟**
1. **建立 `getCallerInfo()`**：
   - 透過 `new Error().stack` 取得錯誤堆疊資訊。
   - 解析 `stack` 找到 **呼叫 `console.log` 的來源**（通常在第 3 行）。
   - 取出 **檔案路徑 + 行號**。

2. **改造 `console.log` 與 `console.error`**：
   - **新增 `getCallerInfo()`**，在每次輸出時記錄「是哪個檔案的哪一行」呼叫 `console.log`。

---

### **精簡示例**
```javascript
const fs = require('fs');
const path = require('path');

// 取得當前執行的檔案名稱與行號
const getCallerInfo = () => {
    const stack = new Error().stack.split("\n");
    const callerLine = stack[3]; // 呼叫 console.log 的實際行
    const match = callerLine.match(/\((.*):(\d+):(\d+)\)/);
    return match ? `${path.basename(match[1])}:${match[2]}` : 'unknown';
};

// 重新定義 console.log
const originalLog = console.log;
console.log = (...args) => {
    const caller = getCallerInfo();
    const message = `[${caller}] ${args.map(arg => JSON.stringify(arg)).join(' ')}`;
    originalLog(message); // 保留原行為
};

// 測試
console.log("這是測試日誌");
```

---

### **輸出示例**
```plaintext
[app.js:25] "這是測試日誌"
```

這樣每次 `console.log` 都能自動帶上「來源檔案與行號」，方便快速定位錯誤！🚀

### `logger.js` 精要說明  

該 `logger.js` 主要功能是 **攔截 `console.log` 和 `console.error`**，並在日誌中 **記錄當前執行的檔案名稱與行號**，
同時寫入 `logs/application_YYYY-MM-DD.log`，以便後續追蹤與除錯。  

---

### **核心功能**
1. **格式化時間**
   - `getCurrentDate(type)`：返回 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm:ss.SSS` 格式的日期時間，作為日誌時間戳與檔名使用。

2. **動態產生日誌檔案名稱**
   - `logFilePath` 會依據當天日期 (`YYYY-MM-DD`) 自動變更，確保日誌按日期分類存放。

3. **覆寫 `console.log` 和 `console.error`**
   - **自動擷取執行的檔案名稱與行號**
   - **記錄 `LOG:` 或 `ERROR:` 以區分日誌類型**
   - **寫入日誌檔案 (`logToFile`)** 並 **保留原始 `console.log` 行為**

4. **日誌寫入機制**
   - `logToFile(message)`：將日誌內容（含時間戳、檔案名稱、行號）同步寫入日誌檔案 (`logs/application_YYYY-MM-DD.log`)。

---

### **優勢**
✅ **自動擷取檔案名稱與行號**，方便查找錯誤源頭  
✅ **不影響原生 `console.log` 行為**，仍可正常輸出到終端  
✅ **日誌自動分類存檔**，可按天存取，便於管理  
✅ **JSON 物件自動轉字串**，確保輸出格式一致  

這樣的寫法，讓 Express 框架在開發與除錯時，能更精確地記錄每次執行的細節！🚀

const fs = require('fs');
const path = require('path');
const { createLogger, format, transports } = require('winston');
const { combine, timestamp, printf } = format;

// 取得當前日期並格式化成 YYYY-MM-DD HH:mm:ss.SSS
const getCurrentDate = (type) => {
    const date = new Date();
    const year = date.getFullYear();
    const month = String(date.getMonth() + 1).padStart(2, '0');
    const day = String(date.getDate()).padStart(2, '0');
    const hours = String(date.getHours()).padStart(2, '0');
    const minutes = String(date.getMinutes()).padStart(2, '0');
    const seconds = String(date.getSeconds()).padStart(2, '0');
    const milliseconds = String(date.getMilliseconds()).padStart(3, '0');

    if (type === 'date') {
        return `${year}-${month}-${day}`;
    } else if (type === 'time') {
        return `${year}-${month}-${day} ${hours}:${minutes}:${seconds}.${milliseconds}`;
    }
};

// 設定 log 檔案的名稱，根據當前日期
const logFilePath = path.join(__dirname, `../../logs/application_${getCurrentDate('date')}.log`);

// Winston 設定
const logger = createLogger({
    format: combine(
        timestamp({ format: 'YYYY-MM-DD HH:mm:ss.SSS' }),
        printf(({ timestamp, level, message }) => {
            return `[${timestamp}] ${level.toUpperCase()}: ${message}`;
        })
    ),
    transports: [
        new transports.File({ filename: logFilePath, level: 'info' })
    ]
});

// 取得當前執行的程式檔案與函式名稱
const getCallerInfo = () => {
    const stack = new Error().stack.split('\n').slice(3);
    const callerLine = stack[0];
    const match = callerLine.match(/\((.*?):(\d+):(\d+)\)/);
    if (match) {
        const filePath = match[1].split('/').slice(-2).join('/'); // 取得相對檔案路徑
        const lineNumber = match[2];
        return `${filePath}:${lineNumber}`;
    }
    return 'unknown';
};

// 重寫 console.log
const originalLog = console.log;
console.log = (...args) => {
    const callerInfo = getCallerInfo();
    const message = args.map(arg => (typeof arg === 'object' ? JSON.stringify(arg) : arg)).join(' ');
    logger.info(`[${callerInfo}] LOG: ${message}`);
    originalLog(...args);
};

// 重寫 console.error
const originalError = console.error;
console.error = (...args) => {
    const callerInfo = getCallerInfo();
    const message = args.map(arg => (typeof arg === 'object' ? JSON.stringify(arg) : arg)).join(' ');
    logger.info(`[${callerInfo}] ERROR: ${message}`);
    originalError(...args);
};

// 匯出日誌功能
module.exports = { logger };
