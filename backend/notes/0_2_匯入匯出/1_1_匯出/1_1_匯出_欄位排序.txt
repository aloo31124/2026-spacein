小g:
------------------------------------------------

這段程式碼目前有幾個需要調整的地方：  

    1. **`room.service.js` 返回的欄位未符合需求**  
    - 目前返回了 `capacity`, `location`, `createdAt`，
    但應該只返回 `id`, `name`, `ownerId`, `isBookingAllSite`。
    
    2. **`room.model.js` 的 `getAllRooms()` 應確保資料順序符合需求**  
    - Firestore 內部是無序的，需要顯式排序（例如：`orderBy()`）。
    - 應調整 `Room` 類別的建構函式，使其與 Firestore 的欄位對應。

---

### **📌 調整後的 `room.model.js`**
    ```javascript
    const db = require('../firestore');
    const COLLECTION_NAME = 'Room';

    class Room {
        constructor(id, name, ownerId, isBookingAllSite) {
            this.id = id;
            this.name = name;
            this.ownerId = ownerId;
            this.isBookingAllSite = isBookingAllSite;
        }

        // 取得所有房間資訊，並依 `id, name, ownerId, isBookingAllSite` 排序
        static async getAllRooms() {
            const snapshot = await db.collection(COLLECTION_NAME).get();
            return snapshot.docs.map(doc => {
                const data = doc.data();
                return new Room(doc.id, data.name, data.ownerId, data.isBookingAllSite);
            });
        }
    }

    module.exports = Room;
    ```

---

### **📌 調整後的 `room.service.js`**
    ```javascript
    const Room = require('../models/room.model');

    exports.getAllRooms = async () => {
        try {
            const rooms = await Room.getAllRooms();
            return rooms
                .map(room => ({
                    id: room.id,
                    name: room.name,
                    ownerId: room.ownerId,
                    isBookingAllSite: room.isBookingAllSite
                }))
                .sort((a, b) => a.id.localeCompare(b.id)); // 依 `id` 進行排序
        } catch (error) {
            throw new Error(`获取房间列表失败: ${error.message}`);
        }
    };
    ```

---

### **📌 重點調整**
    ✅ **只返回指定欄位**：`id`, `name`, `ownerId`, `isBookingAllSite`  
    ✅ **移除多餘欄位**：原本的 `capacity`, `location`, `createdAt` 不再返回  
    ✅ **確保資料順序**：根據 `id` 進行排序（也可根據 `name` 等其他欄位）  

這樣，`/api/backup/room/export/list` API 就會返回符合需求的房間資料 🎯
