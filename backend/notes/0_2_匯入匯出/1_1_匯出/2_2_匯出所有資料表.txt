你目前的四個 `exportAllX()` 函式都寫得很完整了，
現在我們只需要將這四個 API 呼叫整合進 `exportAllDataTable()` 裡，
並使用 `forkJoin` 進行非同步處理，一次性匯出所有資料表。

---

### ✅ 整合後的 `exportAllDataTable()` 實作：

```ts
import { forkJoin } from 'rxjs';

exportAllDataTable() {
  forkJoin({
    users: this.sysDashboardService.exportAllUserList(),
    rooms: this.sysDashboardService.exportAllRoomList(),
    sites: this.sysDashboardService.exportAllSiteList(),
    bookings: this.sysDashboardService.exportAllBookingList()
  }).subscribe({
    next: (res) => {
      // 使用者資料
      if (res.users.exportList?.length) {
        const csv = this.exportService.convertToCSV(res.users.exportList);
        this.exportService.downloadCSV(csv, 'user_all_export.csv');
      } else {
        alert('無可匯出使用者的資料');
      }

      // 教室資料
      if (res.rooms.exportList?.length) {
        const csv = this.exportService.convertToCSV(res.rooms.exportList);
        this.exportService.downloadCSV(csv, 'room_all_export.csv');
      } else {
        alert('無可匯出全部教室資料');
      }

      // 座位資料
      if (res.sites.exportList?.length) {
        const csv = this.exportService.convertToCSV(res.sites.exportList);
        this.exportService.downloadCSV(csv, 'site_all_export.csv');
      } else {
        alert('無可匯出全部座位資料');
      }

      // 預約資料
      if (res.bookings.exportList?.length) {
        const csv = this.exportService.convertToCSV(res.bookings.exportList);
        this.exportService.downloadCSV(csv, 'booking_all_export.csv');
      } else {
        alert('無可匯出預約資料');
      }
    },
    error: (err) => {
      console.error('部分或全部匯出失敗：', err);
      alert('匯出過程中發生錯誤，請查看主控台。');
    }
  });
}
```

---

### 🔧 重點說明：

- `forkJoin` 適用於「**所有 API 都執行完成後再處理**」的情境。
- 每一份資料透過 `convertToCSV()` 處理後，使用 `downloadCSV()` 匯出為檔案。
- 每張表的錯誤與資料缺乏，都有分別處理，避免整體中斷。
- 你也可以額外加個 loading 狀態，例如用 `isLoading = true` 在 UI 上顯示處理中狀態（需要再加 UI 寫法）。
