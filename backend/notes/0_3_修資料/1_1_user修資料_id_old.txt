這段程式碼會將 Firestore `User` 表內的所有文檔，將原本的 `id` 欄位改為 `id_old`，並用 Firestore 的 `document ID` 來作為新的 `id` 欄位，最後更新 Firestore 中的資料。  

---

### **📌 `fixData.service.js`**
```javascript
const db = require('../firestore');
const COLLECTION_NAME = 'User';

class FixDataService {
    static async fixUserIdField() {
        try {
            const snapshot = await db.collection(COLLECTION_NAME).get();

            if (snapshot.empty) {
                console.log('No user data found.');
                return;
            }

            const batch = db.batch(); // 使用批次寫入來提高效率

            snapshot.docs.forEach(doc => {
                const userData = doc.data();

                // 若 `id` 欄位存在，則改為 `id_old`
                if (userData.id) {
                    const updatedData = {
                        id_old: userData.id, // 原 id 變為 id_old
                        id: doc.id // Firestore 的 document ID 作為新的 id
                    };

                    // 準備更新 Firestore
                    const userRef = db.collection(COLLECTION_NAME).doc(doc.id);
                    batch.update(userRef, updatedData);
                }
            });

            // 提交 Firestore 批次更新
            await batch.commit();
            console.log('User data updated successfully.');
        } catch (error) {
            console.error('Error updating user data:', error);
        }
    }
}

module.exports = FixDataService;
```

---

### **📌 這段程式碼的作用**
1. **讀取 Firestore `User` 表的所有文檔**：
   - 使用 `db.collection(COLLECTION_NAME).get();` 獲取所有 `User` 文檔。

2. **批次處理**：
   - Firestore 批次更新 (`batch.update()`) 確保更新過程更高效。

3. **更新邏輯**：
   - `id_old`: 把原來的 `id` 欄位改名為 `id_old`。
   - `id`: 使用 Firestore 自動產生的 `document ID` 來作為新的 `id`。

---

### **🔥 執行修正**
可以在 `controller` 中建立一個 API 來手動觸發修正：
```javascript
const FixDataService = require('../services/fixData.service');

exports.fixUserData = async (req, res) => {
    try {
        await FixDataService.fixUserIdField();
        res.status(200).json({ result: '200', message: 'User data updated successfully.' });
    } catch (error) {
        console.error("[fixUserData] error:", error);
        res.status(500).json({ result: '500', error: error.message });
    }
};
```
在 `index.js` 加入路由：
```javascript
app.post('/api/fix/user/id', backApiController.fixUserData);
```

前端可以請求 `POST /api/fix/user/id` 來執行修正。

---

### **📌 Firestore 修正前後示例**
#### **修正前**
```json
{
    "id": "112285939158270288185",
    "email": "reica2501@gmail.com",
    "name": "_ヒカル"
}
```
#### **修正後**
```json
{
    "id_old": "112285939158270288185",
    "id": "ABC123DEF456",  // Firestore 產生的 document ID
    "email": "reica2501@gmail.com",
    "name": "_ヒカル"
}
```

這樣，Firestore `User` 表的 **`id` 欄位將被 Firestore 自動生成的 ID 取代，而原本的 `id` 則被存為 `id_old`**，確保數據一致性 ✅
