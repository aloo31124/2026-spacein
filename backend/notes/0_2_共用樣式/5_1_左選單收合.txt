您好，為了實現您的需求，您需要在 `RoomDashboardComponent` 的 TypeScript 檔案中管理選單的顯示狀態，並根據按鈕的點擊事件來切換狀態，同時更新樣式以顯示或隱藏選單和圖示。

**修改 `src/app/manager-room/components/room-dashboard/room-dashboard.component.html`：**

1.  **為圖示和選單添加點擊事件處理器。**
2.  **使用 `[style.display]` 綁定來控制元素的顯示/隱藏。**

```html
<div class="manager-container">
  <img
    class="iconBtn"
    src="assets/images/icon/icon_next.png"
    (click)="toggleMenu()"
    [style.display]="isMenuVisible ? 'none' : 'block'"
  />
  <div class="manager-menu" [style.display]="isMenuVisible ? 'flex' : 'none'">
    <img
      class="iconBtn"
      src="assets/images/icon/icon_back.png"
      (click)="toggleMenu()"
    />
    <button routerLink="/manager-room/booking-user" routerLinkActive="active">預約者管理</button>
    <button routerLink="/manager-room/room" routerLinkActive="active">教室管理</button>
    <button routerLink="/manager-room/site" routerLinkActive="active">座位管理</button>
    <button routerLink="/manager-room/booking" routerLinkActive="active">預約紀錄管理</button>
  </div>
  <div class="manager-container">
    <router-outlet></router-outlet>
  </div>
</div>
```

**修改 `src/app/manager-room/components/room-dashboard/room-dashboard.component.ts`：**

1.  **引入 `Component`。**
2.  **宣告一個變數 `isMenuVisible` 來追蹤選單的顯示狀態，預設為 `true` (顯示)。**
3.  **實作 `toggleMenu()` 方法來切換 `isMenuVisible` 的值。**

```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-room-dashboard',
  templateUrl: './room-dashboard.component.html',
  styleUrls: ['./room-dashboard.component.scss']
})
export class RoomDashboardComponent {
  isMenuVisible: boolean = true; // 預設選單是顯示的

  toggleMenu() {
    this.isMenuVisible = !this.isMenuVisible;
  }
}
```

**修改 `src/app/manager-room/components/room-dashboard/room-dashboard.component.scss`：**

您需要確保 `.iconBtn` 的樣式適用於兩個圖示。

```scss
.manager-container {
  width: 90vw;
  display: flex;
  flex-direction: row;
  justify-content: flex-start;
  align-items: flex-start;
  padding: 40px;

  .iconBtn {
    cursor: pointer; // 讓圖示看起來可以點擊
    margin-right: 10px; // 為 icon_back 提供一些右邊距
  }

  .manager-menu {
    display: flex;
    flex-direction: column;
    justify-content: flex-start;
    align-items: flex-start;
    padding: 20px;
    min-width: 220px;
    background: #661983;
    border-radius: 20px;

    .iconBtn {
      margin-bottom: 15px; // 為 icon_back 提供一些下邊距
    }
  }

  .manager-menu button.active {
    background: #FBE0FF;
    color: #661983;
    font-weight: bold;
  }

  .manager-container {
    display: flex;
    flex-direction: column;
    justify-content: flex-start;
    align-items: flex-start;
    padding: 20px 40px;

    .search-bar {
      display: flex;
      flex-direction: row;
      justify-content: flex-start;
      align-items: center;
      gap: 20px;
    }
  }
}
```

**總結修改：**

* **HTML (`room-dashboard.component.html`)：**
    * 為 `icon_next.png` 和 `icon_back.png` 添加了 `(click)="toggleMenu()"` 事件綁定。
    * 使用 `[style.display]` 綁定根據 `isMenuVisible` 的值來顯示或隱藏 `icon_next.png` 和 `.manager-menu`。注意 `.manager-menu` 的 `display` 屬性在顯示時設置為 `flex` 以保持其內部元素的正確佈局。
* **TypeScript (`room-dashboard.component.ts`)：**
    * 宣告了 `isMenuVisible` 屬性，預設為 `true`。
    * 實作了 `toggleMenu()` 方法來切換 `isMenuVisible` 的值。
* **SCSS (`room-dashboard.component.scss`)：**
    * 添加了基本的 `cursor: pointer` 樣式到 `.iconBtn`，使其看起來可點擊。
    * 調整了圖示的間距。

現在，當頁面載入時，`manager-menu` 會預設顯示，`icon_next.png` 會隱藏。當您點擊 `icon_back.png` 時，`manager-menu` 會收合隱藏，`icon_next.png` 會出現。點擊 `icon_next.png` 會恢復原始狀態。
