### **📌 解法 1：使用 `CSS Grid`**
    ```css
    .home-list-container {
        width: 80%;
        max-width: 800px;

    .home-list-container {

        max-width: 800px;

        flex-wrap: wrap;
        justify-content: center; /* 確保按鈕置中 */
        gap: 40px;
        padding: 40px;
        border: 2px solid red;
    }

如下 .home-list-container html 元素為一個容器,
裡面有多個等寬的大按鈕, 大按鈕寬度一致,
在不知道大按鈕寬度的情況下, 
請設計為兩欄樣式, 但大按鈕都置中,
視窗伸縮中, 若寬度過窄則變為一欄, 大按鈕寬度不變。

舊的寫法
.home-list-container {
    width: 80%;
    max-width: 800px;
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    justify-content: flex-start; // -------------------------------------- > 此處錯誤
    align-items: center;
    padding: 40px;
    gap: 40px;
    border: 2px solid red;
}

小g 回答完整, 兩種解法:
------------------------------------------------

你可以使用 **CSS Grid** 或 **Flexbox** 來實現這個兩欄布局，
當視窗變窄時自動變為一欄，
但 **按鈕寬度保持不變且置中**。  

以下是最佳解法：
    - **大按鈕寬度一致，且始終置中**。
    - **當容器寬度不足時，自動換行為一欄**。

---

### **📌 解法 1：使用 `CSS Grid`**
    ```css
    .home-list-container {
        width: 80%;
        max-width: 800px;
        display: grid;
        grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); /* 自適應 2 欄 */
        justify-content: center; /* 讓按鈕置中 */
        gap: 40px;
        padding: 40px;
        border: 2px solid red;
    }

    .home-list-button {
        width: 250px;  /* 固定按鈕寬度 */
        height: 60px;
        text-align: center;
        line-height: 60px;
        background-color: #0075ff;
        color: white;
        font-size: 18px;
        border-radius: 5px;
    }
    ```

**🎯 運作方式**
    - `grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))`  
    → 當寬度足夠時，自動擴展為 2 欄。當空間不足時，會變成 1 欄。
    - `justify-content: center;`  
    → 確保按鈕 **在可用空間內水平置中**。
    - `width: 250px;`  
    → 按鈕寬度固定，不會變窄。

---

### **📌 解法 2：使用 `Flexbox`**
    ```css
    .home-list-container {
        width: 80%;
        max-width: 800px;
        display: flex;
        flex-wrap: wrap;
        justify-content: center; /* 確保按鈕置中 */
        gap: 40px;
        padding: 40px;
        border: 2px solid red;
    }

    .home-list-button {
        width: 250px;  /* 固定按鈕寬度 */
        height: 60px;
        text-align: center;
        line-height: 60px;
        background-color: #0075ff;
        color: white;
        font-size: 18px;
        border-radius: 5px;
    }
    ```

### **📌 完整 HTML + CSS**
    ```html
    <!DOCTYPE html>
    <html lang="zh-TW">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>兩欄按鈕佈局</title>
        <style>
            .home-list-container {
                width: 80%;
                max-width: 800px;
                display: flex;
                flex-wrap: wrap;
                justify-content: center;
                gap: 40px;
                padding: 40px;
                border: 2px solid red;
                margin: auto;
            }

            .home-list-button {
                width: 250px;
                height: 60px;
                text-align: center;
                line-height: 60px;
                background-color: #0075ff;
                color: white;
                font-size: 18px;
                border-radius: 5px;
            }
        </style>
    </head>
    <body>

        <div class="home-list-container">
            <div class="home-list-button">按鈕 1</div>
            <div class="home-list-button">按鈕 2</div>
            <div class="home-list-button">按鈕 3</div>
            <div class="home-list-button">按鈕 4</div>
        </div>

    </body>
    </html>
    ```

---

### **📌 運作方式**
    1. **正常狀態**（視窗寬度 > 550px）：2 欄排列，按鈕間距 40px。
    2. **視窗變窄時**（視窗寬度 ≤ 550px）：自動變為 1 欄。
    3. **按鈕始終置中，寬度不變（250px）**。

    🚀 **推薦 `CSS Grid`，因為它可以更流暢地適應不同的視窗大小！** 🎯
