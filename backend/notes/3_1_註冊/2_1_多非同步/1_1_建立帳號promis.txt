如下 angular 元件, 
將 sendMail, addUser, updateUser 三者非同步 api 取資料整合,
sendMail 完成才執行 addUser, addUser 執行完才執行 updateUser,
若失敗 alert 提醒, 
三者都完成後最後才執行 routeUrlRecordService.nextPage 路由導向

space-in-ng-v2/src/app/auth-route/components/register-info/register-info.component.ts
    import { Component } from '@angular/core';
    import { RegisterService } from '../../services/register.service';
    import { RouteUrlRecordService } from 'src/app/auth-route/services/route-url-record.service';

    @Component({
      selector: 'app-register-info',
      templateUrl: './register-info.component.html',
      styleUrls: ['./register-info.component.scss']
    })
    export class RegisterInfoComponent {

      mail = "";
      isLoading = false;

      constructor(
        private registerService: RegisterService,
        private routeUrlRecordService: RouteUrlRecordService<{}>,
      ) {}

      sendMail() {
        if(this.mail.trim() === "") {
          alert("請輸入信件");
          return;
        }
        // 送信驗證碼
        this.registerService.sendMail(this.mail)
          .subscribe(
            res => {},
            err => {}
          );
        // 建立使用者
        this.registerService.addUser(this.mail)
          .subscribe(
            res => {},
            err => {}
          );
        // 更新使用者
        this.registerService.updateUser(this.mail)
          .subscribe(
            res => {},
            err => {}
          );
        // 送信驗證碼, 建立使用者
        this.routeUrlRecordService.nextPage("register-mail-verify", {mail: this.mail});
      }

    }

gpt 完整：
------------------------------------------------
你要的流程是 **sendMail ➝ addUser ➝ updateUser ➝ nextPage**，
且要確保每一步都成功才執行下一步，否則中止並 alert 錯誤訊息。

這種情境很適合用 `RxJS` 的 `switchMap` 串接非同步流程。

### ✅ 修改版 `sendMail()`：串接非同步流程 + 錯誤處理 + 成功導向頁面

```ts
import { Component } from '@angular/core';
import { RegisterService } from '../../services/register.service';
import { RouteUrlRecordService } from 'src/app/auth-route/services/route-url-record.service';
import { catchError, switchMap, of } from 'rxjs';

@Component({
  selector: 'app-register-info',
  templateUrl: './register-info.component.html',
  styleUrls: ['./register-info.component.scss']
})
export class RegisterInfoComponent {

  mail = "";
  isLoading = false;

  constructor(
    private registerService: RegisterService,
    private routeUrlRecordService: RouteUrlRecordService<{}>,
  ) {}

  sendMail() {
    if (this.mail.trim() === "") {
      alert("請輸入信件");
      return;
    }

    this.isLoading = true;

    this.registerService.sendMail(this.mail).pipe(
      switchMap(() => {
        return this.registerService.addUser(this.mail);
      }),
      switchMap(() => {
        return this.registerService.updateUser(this.mail);
      }),
      catchError((err) => {
        this.isLoading = false;
        alert("處理失敗：" + (err?.error?.message || err.message || '未知錯誤'));
        return of(null); // 結束流程，不會進入 subscribe
      })
    ).subscribe((result) => {
      if (result !== null) {
        this.isLoading = false;
        this.routeUrlRecordService.nextPage("register-mail-verify", { mail: this.mail });
      }
    });
  }

}
```

---

### ✅ 說明

| 步驟 | 功能 |
|------|------|
| `sendMail()` | 發送驗證信 |
| `switchMap()` | 每一步都在前一步成功後才執行下一步 |
| `catchError()` | 任一步失敗就會進來這裡，顯示錯誤並中止流程 |
| `subscribe()` | 最後一層才導頁 |
